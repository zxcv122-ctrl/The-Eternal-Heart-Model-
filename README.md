# The Eternal Heart: The One-Two-Three Model of Evolution

**Author:** Nachangyong

## 📖 About the Project
This repository contains the official Python implementation of the **One-Two-Three Model of Evolution**. It is an exploratory framework that bridges Eastern philosophy (Taiji, Yin-Yang, Five Elements) with modern computational modeling and system dynamics.

## 📂 Repository Structure
*   `five_elements_self_check.py`: A self-check tool based on the Five Elements scoring and evolution simulation.
*   **[USAGE.md](USAGE.md)**: Detailed instruction manual (in Chinese) for the Five Elements self-check tool.
*   *(More core algorithms from the book will be uploaded soon...)*

## ⚙️ How to Run
1. Ensure you have Python 3 installed.
2. Clone the repository.
3. Run the script directly in your terminal: `python five_elements_self_check.py`
