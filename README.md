## 📖 About the Project
This repository contains the official Python implementation of the **One-Two-Three Model of Evolution**. It is an exploratory framework that bridges Eastern philosophy (Taiji, Yin-Yang, Five Elements) with modern computational modeling and system dynamics.

## 📂 Repository Structure
*   `five_elements_self_check.py`: A self-check tool based on the Five Elements.
*   [USAGE.md](USAGE.md): Instruction manual (in Chinese) for the Five Elements tool.
*   `Strategic_Sandbox_Engine.py`: A reverse-trace strategic solver (V7.6.3).
*   [USAGE_SANDBOX.md](USAGE_SANDBOX.md): 说明书 (中文版 / English Version).

## ⚙️ How to Run
1. Install Python 3.
2. Run the scripts:
   `python five_elements_self_check.py`
   `python Strategic_Sandbox_Engine.py`
